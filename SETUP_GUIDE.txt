🎯 QUICK START GUIDE

─────────────────────

──────────────────────────

🎯 INCIDENT WORKFLOW

1. CREATE INCIDENT
   → Go to "Create Incident"
   → Fill in title, type, severity, description
   → Submit

2. ASSIGN INCIDENT
   → As Admin: Click "Assign" on incident
   → Select analyst and deadline
   → Submit

3. INVESTIGATE

   → Upload evidence files
   → Update incident status

4. RESOLVE

   → Adds resolution summary

5. REPORT
   → View incident in reports

🐛 TROUBLESHOOTING

ISSUE: "Database Connection Failed"
SOLUTION: 
  → Start MySQL in XAMPP
  → Verify cyber_ir database exists in PhpMyAdmin
  → Check credentials in config/db.php

ISSUE: "Login not working"
SOLUTION:
  → Clear browser cookies (Ctrl+Shift+Delete)
  → Verify database tables exist via test_connection.php
  → Try demo credentials exactly as shown above

ISSUE: "Cannot upload evidence"
SOLUTION:
  → Check uploads/ folder has write permissions
  → File must be < 10MB
  → File type must be: jpg, png, pdf, log, txt, csv, zip

ISSUE: "Permission Denied"
SOLUTION:
  → Check your user role has required permissions
  → Only admins can assign/close incidents
  → Only analysts can add logs to assigned incidents
